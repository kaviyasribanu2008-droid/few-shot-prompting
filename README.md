
Create Few-Shot Prompts

AI Tool: ChatGPT

Objective: To improve AI responses using examples.

Prompt:
Classify the sentiment.

Examples:

- "I love this product" → Positive
- "This is very bad" → Negative

Input: "The service is excellent."

Output: Positive

Result: Examples help AI understand and answer correctly.

Conclusion: Few-shot prompting improves AI accuracy.
